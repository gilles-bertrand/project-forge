## Blockers / Notes

- **Pattern de référence P2** : `@libs/users-backend` est la référence canonique à mimer pour toutes les routes P2 (cf. §2.0 du plan P2). Invariants : tableau `Route[]`, `setErrorHandler` → `jwtAuthMiddleware` → `for (route of routes) route.routeDefinition(f)`.
- **`repository.insert()` bug** : toujours utiliser `em.create() + em.flush()` pour les tests qui ont des entités avec `onCreate`/`onUpdate`. `insert()` bypass les hooks MikroORM.
- **pnpm-lock.yaml** : le hook `damage-control` bloque `git add pnpm-lock.yaml` explicitement. Utiliser `git add -u` pour stager les fichiers tracés modifiés (dont le lock) sans nommer le chemin.
- **P2 dépendances Fastify** : `scrum-backend/package.json` et `time-tracking-backend/package.json` n'ont pas encore les deps Fastify (non nécessaires en P1). Les ajouter en tout début de P2 (P2.1 infrastructure).
- **ADR DDD** : la lib `scrum-backend` est un bounded context, pas 4 libs séparées. TimeEntry est séparé parce que Scrum ≠ time tracking (remplaçable par Toggl/Harvest).
- **Tests intégration** : nécessitent Docker démarré (`docker compose up -d` à la racine). En local : `pnpm -F @libs/users-backend test`. En CI : testcontainers automatique.

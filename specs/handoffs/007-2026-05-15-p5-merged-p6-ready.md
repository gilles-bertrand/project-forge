### Leçons techniques importantes
- **pretest: "rollup -c"** obligatoire dans `package.json` des libs pour que les tests intégration trouvent le `dist/`
- **TestApp sans moduleRegistry()** → évite les reloads Vite liés aux imports de libs Workspace
- **Placeholders shell-front** : quand une nouvelle lib override une route déjà dans shell-front, il faut supprimer le placeholder de shell-front SINON il écrase la nouvelle template (ordre résolution app-js Embroider)
